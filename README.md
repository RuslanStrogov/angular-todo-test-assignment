## 📋 О проекте

Классическое Todo-приложение, выполненное в рамках тестового задания на позицию Frontend Developer (Angular).

### 🎯 Функциональность

| Фича | Статус |
|------|--------|
| 📋 Отображение списка задач из `TodoStoreService` | ✅ |
| ➕ Добавление новой задачи | ✅ |
| ✏️ Редактирование задачи | ✅ |
| 🗑️ Удаление задачи | ✅ |
| ✅ Изменение статуса (выполнено/активно) | ✅ |
| ⭐ Изменение важности задачи | ✅ |
| 🔄 Сортировка по дате, важности, статусу | ✅ |
| 🔍 Фильтрация задач | ✅ |
| 📊 Статистика (всего / активно / выполнено) | ✅ |
| 🎨 Кастомные чекбоксы | 🟢 (плюс) |
| ✨ Анимации добавления/удаления | 🟢 (плюс) |
| 🧩 Независимый модуль с роутингом | 🟢 (плюс) |
| 📝 Несколько списков | 🟢 (advanced) |

## 🚀 Быстрый старт

```bash
# Установка зависимостей
npm install

# Запуск dev-сервера
npm start          # или: ng serve

# Сборка
npm run build      # или: ng build --prod

# Тесты
npm test           # или: ng test
```
